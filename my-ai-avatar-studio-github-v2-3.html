④ Avatar ပုံ

အသုံးပြုခွင့်ရှိတဲ့ ကိုယ်ပိုင်ပုံ သို့မဟုတ် Avatar ပုံကို ရွေးပါ။

⑤ Avatar Video ဖန်တီးရန်

အခမဲ့စမ်းသပ်ဗားရှင်းမှာ Script၊ အသံဖိုင်နဲ့ Avatar ပုံကို ပြင်ဆင်နိုင်ပါတယ်။ နောက်တစ်ဆင့်အဖြစ် CapCut ထဲမှာ ပုံ၊ MP3 နဲ့ စာတန်းကို ပေါင်းပြီး MP4 ထုတ်ပါ။

  1. CapCut ကိုဖွင့်ပြီး New project ကိုနှိပ်ပါ။
  2. Avatar ပုံကို ရွေးထည့်ပါ။
  3. Audio ထဲက ဖုန်းထဲသိမ်းထားတဲ့ MP3 ကို ထည့်ပါ။
  4. Text ကိုနှိပ်ပြီး Script စာတန်းထည့်ပါ။
  5. ပုံရဲ့ကြာချိန်ကို အသံနဲ့ကိုက်အောင် ညှိပါ။
  6. Export ကိုနှိပ်ပြီး MP4 အဖြစ် သိမ်းပါ။
